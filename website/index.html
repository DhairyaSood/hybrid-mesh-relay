HOW IT WORKS

Nearby first. Further when needed.

Neyra explores a combination of direct phone connections and portable relays. The aim is to move small messages even when conventional connectivity is unavailable.

Nearby connections

Phones connect directly

Nearby Android phones can connect over Wi-Fi peer-to-peer and Bluetooth Low Energy. This local path is designed to work without a cellular connection or internet access.

Longer-range relay

Small relays bridge the gap

A phone can connect to a nearby relay over BLE. Relay devices can then pass small packets over LoRa, extending the path beyond the immediate phone-to-phone range.

THE PRODUCT

Built around a few practical ideas.

Neyra is being developed in the open. These are the core ideas behind the prototype, with implementation and reliability continuing to evolve.

Messaging without the internet

Explore direct device-to-device messaging when a cellular connection or internet access is not available.

Portable relay devices

ESP32-based hardware is being explored to pass messages between phone groups that are farther apart.

More than one connection path

The design combines local Wi-Fi peer-to-peer and BLE links with longer-range relay hops.

Store and forward

The system is designed to hold messages and pass them along when a suitable relay path becomes available.

Understand message state

Message transport states are part of the app; end-to-end delivery confirmation and reliability remain areas to test.

Useful diagnostics

Inspect nearby devices, relay nodes and transport details while testing the prototype.

Neyra is an experimental project, not a substitute for emergency communications. Supported features and behaviour can vary by build and device; check the project status before testing.

Active development

Neyra is an experimental, open-source Android prototype. It is being tested as an engineering project and is not a production-grade or emergency communications service.

GET STARTED

Try Neyra on Android.

The prototype is distributed as an APK outside Google Play. Install it only if you're comfortable testing experimental software.

  1. Download the APK.
  2. Open the downloaded file on Android.
  3. Allow installation from the browser or file manager if prompted.
  4. Install the app and grant the requested wireless permissions.
