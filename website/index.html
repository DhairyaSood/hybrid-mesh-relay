Hybrid Mesh Relay

Resilient communication, without infrastructure.

An experimental offline communication system that combines smartphone peer-to-peer networking with portable long-range relay nodes to keep messages moving when conventional connectivity is unavailable.

A two-tier architecture

Hybrid Mesh Relay isn't only a phone mesh or only a LoRa network — it's designed as a hybrid of both.

Local mesh

Phone to phone

Nearby smartphones talk directly to each other over infrastructure-free peer-to-peer wireless — no towers, no internet, no server in between.

Portable relay

Relay to relay

When a direct local path isn't available, a portable relay bridges the gap — BLE between phone and relay, LoRa between relay nodes.

What it does

Offline messaging

Exchange messages without relying on cellular service or internet connectivity.

Portable relay nodes

Low-cost ESP32-based devices extend communication between separated phone clusters.

Hybrid networking

Combines local phone-to-phone links with long-range relay hops.

Store and forward

Relay nodes queue messages temporarily and forward them once a path opens up.

Delivery tracking

Every message carries a transport state — queued, relaying, delivered.

Network visibility

See nearby devices, relay nodes and transport diagnostics as they happen.

Active development

An experimental, open-source engineering project — developed and evaluated through controlled testing, not presented as a production-grade emergency communications service.
