Hybrid Mesh Relay

Resilient communication, without infrastructure.

Hybrid Mesh Relay is an experimental offline communication system that combines smartphone peer-to-peer networking with portable long-range relay nodes to keep messages moving when conventional connectivity is unavailable.

Built for resilient communication

Hybrid Mesh Relay uses a two-tier communication architecture, designed around a hybrid model rather than being only a smartphone mesh or only a long-range LoRa network.

Tier 1

Local phone mesh

Smartphones communicate directly with nearby smartphones using infrastructure-free peer-to-peer wireless communication — no cell towers, no internet, no central server.

Tier 2

Portable relay bridge

When a direct local path is unavailable or unreliable, a portable relay can bridge communication using BLE between the phone and relay, and LoRa between relay nodes.

Phone A → Relay A → Relay B → Phone B

What it does

A compact set of capabilities aimed at keeping messages moving when the network can't.

Offline messaging

Messages can be exchanged without relying on cellular service or internet connectivity.

Hybrid networking

Combines local smartphone communication with portable long-range relay nodes.

Portable relay nodes

Low-cost ESP32-based relay devices extend communication between separated phone clusters.

Store and forward

Messages can be temporarily queued by relay nodes and forwarded once a path becomes available.

Delivery tracking

Messages expose useful delivery and transport states such as queued, relaying and delivered.

Network visibility

Inspect nearby devices, relay nodes, transport state and useful diagnostics.

Project status

Active development

Hybrid Mesh Relay is an experimental, open-source engineering project. It is being developed and evaluated through controlled testing, and is not presented as a production-grade emergency communications service.
