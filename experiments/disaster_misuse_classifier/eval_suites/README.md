# Independent evaluation suites (not for training/tuning)

Hand-authored JSONL files for stress-testing **frozen** models. Not generated by template jitter.

| Suite | Focus |
|-------|--------|
| `independent_robustness_v1.jsonl` | General robustness (80 cases) |
| `civic_emergency_challenge_v1.jsonl` | Traffic, official-style notices, school help, impersonation (48 cases) |
| `civic_emergency_challenge_v2.jsonl` | Harder independent suite: figurative language, contrast pairs, trigger words (73 cases) |

Full v2 comparison (MU-v1 vs MU-v2): `docs/CIVIC_CHALLENGE_V2_EVAL.md` and `scripts/eval_civic_challenge_v2_full.py`.

```bash
cd experiments/disaster_misuse_classifier
python scripts/eval_robustness_suite.py --suite eval_suites/<suite>.jsonl \
  --model models/synthetic_baseline/synthetic_misuse_tfidf_logreg.joblib
python scripts/summarize_challenge_eval.py outputs/robustness_eval_<run_id>/results.json
```

Labels are **advisory content categories**, not proof of criminality. Classification cannot verify sender identity or whether a message is genuinely government-issued.
