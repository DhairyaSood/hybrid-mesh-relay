# Dataset card — synthetic disaster misuse messages (10k)

## Provenance

| Field | Value |
|-------|--------|
| **Name** | `synthetic_misuse_10k` |
| **Version** | seed `42`, generator in `synthetic/` |
| **Source** | Fully **synthetic**; no tweets, private messages, or Nepal/India corpus text |
| **Purpose** | Offline training/evaluation of misuse **content** classifiers for Neyra research |
| **Licence** | Generated by project scripts; no third-party text |

## Generation

```bash
cd experiments/disaster_misuse_classifier
pip install -r requirements.txt
python scripts/generate_synthetic_dataset.py --config configs/synthetic_dataset.yaml
python scripts/validate_synthetic_dataset.py
python scripts/split_synthetic_dataset.py
```

Config: `configs/synthetic_dataset.yaml`.  
Label definitions: `docs/SYNTHETIC_DATASET_LABELS.md`.

Labels are set from **scenario type** (`label_source=generator_scenario`), not keyword rules on the final string.

## Composition

- **10,000** unique messages (normalized text deduplicated at generation).
- **5,000** English (`language_bucket=english`, `language_subtype=english`).
- **5,000** Hindi/Hinglish (`language_bucket=hindi_hinglish`), split between **Devanagari Hindi** and **Latin-script Hinglish** (~50/50 of that half unless rounding adjusts).

## Splits

- **Unit of split:** `template_family_id` (not random rows).
- **Ratios:** ~70% / 15% / 15% families → `data/synthetic_misuse_10k/splits/{train,validation,test}.jsonl`
- Manifests: `data/synthetic_misuse_10k/manifests/*_families.txt`
- Leakage check: `split_report.json` (`family_leakage` must be false).

## Limitations (do not over-claim)

- Fiction; patterns may not match real mesh traffic or regional language use.
- Threat/fraud wording is **vague** by design (no operational harm or scam instructions).
- **Cannot** establish real-world accuracy or fairness; human audit and real labelled data still required.
- Not for automated blocking or criminal findings.

## Storage

Under `data/` per `.gitignore` — do not commit generated JSONL to git unless policy changes.

## Schema (JSONL fields)

| Field | Description |
|-------|-------------|
| `sample_id` | `SYNTH-<sha256>` |
